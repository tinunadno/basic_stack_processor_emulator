 - ОП КОДЫ:
    31      30      29      28      27      26      25      24
|-------|-------|-------|-------|-------|-------|-------|-------|
    |       |       |       |
    |       |       |      бит векторных операций
    |       |       |
    |       |      бит манипулированием регистрами + всякие дополнительные вещи
    |       |
    |      бит инструкций по перемещению данных и работы со стеком
    |
   бит инструкций по потоку управления

если все первые биты пустые то это просто скалярная арифмитическая операция

    - оп коды скалярных арифмитических и логических операций над двумя верхними элементами стека:
        0b0000_0000: or
        0b0000_0001: and
        0b0000_0010: not
        0b0000_0011: add
        0b0000_0100: mul
        0b0000_0101: div
        0b0000_0111: >>
        0b0000_1000: <<
        0b0000_1001 - 0x0000_1111 (пока свободны если придумаю что-нибудь воткну)

    - оп коды векторных арифмитических операций
        0b0001_0000: or
        0b0001_0001: and
        0b0001_0010: not
        0b0001_0011: add
        0b0001_0100: mul
        0b0001_0101: div
        0b0001_0111: >>
        0b0001_1000: <<
        0b0001_1001 - 0x0000_1111 (пока свободны если придумаю что-нибудь воткну)

    - оп инструкций по перемещению данных и работы со стеком
        0b0100_0000: lit - прямая загрузка значения в стек
        0b0100_0001:     - поместить значение по адресу в стек
        0b0100_0011:     - поместить значние по адресу регистра "a" в стек
        0b0100_0100:     - поместить значние по адресу регистра "b" в стек
        0b0100_0101:     - поместить значение верхушки стека в регистр "a"
        0b0100_0110:     - поместить значение верхушки стека в регистр "b"
        0b0100_0111:     - поместить значение регистра "а" в стек

         ДАЛЕЕ МНЕ ПОКА ЛЕНЬ ПИСАТЬ

    - вспомогательные опт команды
        0x1111_1111: halt - конец программы


 - Идея векторной хуйни:
    при добавлении определённого бита в ОП код операции будут выполняться в векторном режиме например add
    Пример:
        стек всё ещё 32 битный просто элементы там начинают восприниматься как 16 битные числа ->
        сложения двух верхних элементов стека в векторном режиме выглядит как
        | a_high : a_low |
                 +          = |a_high + b_high : a_low + b_low|
        | b_high : b_low |
        на выходе получаем 2 новых числа которые можем положить на стек
